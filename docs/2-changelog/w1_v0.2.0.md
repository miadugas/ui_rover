## Changes

- **Read pipeline** (`src/features/palette/read/`): `readPalette` orchestrator — swatch-blob detection (two passes: card-scale + small chips) → **auto-crop** = the non-edge blob containing the most small blobs (≥1.5 % area, unpadded) → OCR only on a crop (two sub-rect passes: card @1200 px + right 45 % column @1000 px, unioned, early stop at 5) → source selection `ocr` (≥3) / `blobs` (≥3) / `quantize`; all candidates kept for review. Measured on the real dopely fixture: 5/5 codes (4 exact + `#d0d5dd` offered as repaired).
- **OCR** (`ocrConfig`, `ocrWorker`, `ocrHexCodes`, `hexTokens`, `blobSpace`): bundled Tesseract.js v7 (LSTM, PSM AUTO, whitelist off — set by the recorded spike in `docs/6-memo/ocr-spike.md`), lazy same-origin worker (`cacheMethod: 'none'`, absolute asset URLs, 60 s idle teardown), abort racing with a generation token, `#` + hex word join, conservative repairs, bare tokens accepted only near a blob mapped into the pass's coordinate space.
- **Crop** (`cropRect`, `cropToBlob`, `CropTool`): drag/move/resize/keyboard crop over the source image (object-fit-contain mapping), smooth upscale to a target width; crop persisted per entry, bound to the source image id, ignored when stale.
- **Review panel** (`ReadPalettePanel`): progress with cancel, candidate rows with source badges / confidence / repaired marker, checkboxes, Apply (replace) / Append (swatches only), "Keep this crop" for auto-crops, focus restored after apply/dismiss.
- **Wiring**: Capture reads on save (progress on the Save button, Cancel read → quantize fallback) and hands the result to the entry page as a one-shot router-state review; entry-page first extract on designs also reads; `MockPanel` is the single owner of palette + crop writes (`editorRect` vs persisted `crop`, optimistic save with revert + Retry).
- **Data**: `Entry.paletteSource`, `Entry.crop` (optional; export format unchanged, validated when present); `db.updateEntry` drops `undefined` keys.
- **Tooling**: `scripts/copy-ocr-assets.mjs` on `predev`/`prebuild` → `public/ocr/` (gitignored, ≈15 MB on disk, ≈7 MB fetched once per session); spike harness `scripts/spike/ocr-spike.mjs`; fixture `docs/6-memo/fixtures/dopely-calm-saas.png`.
- **Tests**: 311 (was 184), incl. blob-space mapping, abort races, crop revert, auto-crop selection on a synthetic buffer.
