## Changes

- **Component capture** (`src/features/components/`): on a design entry, *Capture component* opens the existing `CropTool` on a snapshot of the selected screenshot (carousel locked while open) → `cropComponent` makes a natural-size WebP crop + thumb → `ComponentForm` (14 fixed chips + free tags + note) → one `createEntry`. Components are first-class entries (`kind: 'component'`) with provenance — `parentId`, `parentImageId`, `sourceRect` — while `sourceImageId` keeps meaning "this entry's own image", so the palette read works on them unchanged.
- **Surfaces**: Components strip on the parent page (thumbs, chips, remove, focus on the new item); component entry view (badge, parent link + thumbnail, editable chips through the page's debounced owner, Extract palette, no nested capture); library `Component` kind filter, component-type chip row, component cards with "from <post>"; Recent row titles resolve the parent.
- **URL optional**: `url` / `platform` / `shortcode` are optional — a screenshot alone can be captured; `entryTitle()` supplies "Untitled capture" / "Component of …"; badges and the source link render only when a URL exists; the entry id is the identity.
- **Persistence** (`src/lib/db.ts`): IndexedDB **schema v2** — `by-parent` index via a version-aware `upgrade(db, oldVersion)`; `storageFallbackReason()` with a distinct "upgrade failed" banner; component relationships validated inside the create transaction; one-level cascade delete in one transaction; `listChildren`; in-memory fallback parity including URL-less dedupe.
- **Import/export** (`src/lib/export.ts`): format still v1; optional URL trio and component fields validated; pure two-pass `resolveImport` (collisions, then the parent set that exists after the operation — Merge vs Replace), parents-first writes, `{ imported, skipped, orphaned }` rendered by the backup panel.
- **Shared**: `src/components/chipStyles.ts`; `CaptureKind` keeps capture to palette | design.
- **Verified in the browser**: v1 → v2 upgrade kept existing entries; URL-less capture; two components captured (462×584 card, 212×118 button) and filtered; palette read on a component returned `ocr` with provenance intact; deleting the parent removed both children.
- **Tests**: 412 (was 311), 46 files.
