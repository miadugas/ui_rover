## Changes

- **Capture** (`src/features/capture`): Instagram (`/p/`, `/reel/`, `/reels/`, user-prefixed) and Threads (`threads.net` / `threads.com`) URL parsing + normalization; paste / drop / picker intake of up to 10 screenshots (12 MB each) with capture-time thumbs; palette | design kind toggle; Save disabled without an image or on a duplicate URL (link to the existing entry); extraction failure falls back to a design entry with a notice carried via router state.
- **Palette pipeline** (`src/features/palette`): Canvas downsample ≤160px → median-cut quantize → dedupe → luminance sort → role assignment (background / surface / text / muted / primary / accent); zero colors throws `ExtractionError`; 1–2 colors flagged degraded; pick-from-image via `mapContainClick` + `samplePixel`.
- **Wireframe mock** (`src/features/palette/mock`): data-driven spec (template → frames → sections → blocks) with per-frame `renderKey` and template-scoped shared `overrideKey`; 11 templates (Mia's e-commerce web + mobile pair, classic, two-column, three-column, sidebar, dashboard, blog, portfolio, saas-landing, documentation, components sheet with a `code` composite); every block is a touchpoint — role-level recolor by default, "just this block" override, clear override; editable swatch strip (copy, remove ≥1, add hex, pick from image, reset roles, reset palette); template choice persisted per entry.
- **Entry page** (`src/app/EntryPage.tsx`): image carousel with source marker, device frame for designs, "Extract palette" on design entries (single persistence owner in `MockPanel`), tags + notes autosave, delete with confirm and retryable error, post-save heading focus.
- **Library** (`src/features/library`, `src/app/LibraryPage.tsx`): grid with intersection-triggered thumbs, kind / platform / tag filters + text search, empty and no-results states, export / import panel (v1 JSON with full schema validation, decode-then-write, merge-by-URL all-or-nothing or replace-all with double confirm, 150 MB warning).
- **Persistence** (`src/lib/db.ts`, `useLibrary.ts`, `useDebouncedPatch.ts`): `idb` schema v1 (`entries` with unique `by-url`, `images` with `by-entry`), atomic create / delete / import / replace, per-entry serialized `updateEntry`, in-memory fallback + banner; debounced patches with flush on blur / unmount / hidden / pagehide, failed-write retention + retry, `discard()` with a generation counter.
- **App shell**: `HashRouter` routes `#/`, `#/library`, `#/entry/:id`; neutral chrome tokens in `@theme`, light + dark; shared `Button` / `Badge` / `Field` / `Popover` primitives.
- **Tooling**: Vitest + jsdom + Testing Library + fake-indexeddb (28 files, 181+ tests), `DOM.Iterable`, jsdom stubs in `src/test/setup.ts`; README rewritten; template assets removed.
- **Docs**: ARCHI.md rewritten as built (no "(planned)" sections), TESTING.md, project CLAUDE.md, tutorial `docs/5-tuto/tuto_0.1.0.md` (one persistence owner per field group).
